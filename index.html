.gwcu

One local truth file. No diary.

{ "apps": {}, "calibration": {}, "capabilities": {}, "observed": {}, "preferences": {}, "schema": "gwcu.truths.v1" }

observed, capabilities, calibration, and apps are generated truth. preferences are user-owned and survive generated-truth regeneration. GWCU stores conclusions, not screenshots, task history, user text, raw health dumps, focus state, or transient geometry.

Repo and non-Git scope

GWCU_SCOPE_ROOT override → nearest ancestor already containing .gwcu → Git worktree root → current working directory

That nearest-existing rule makes a general non-Git workspace first-class. Put one .gwcu at a workspace root and descendants reuse it. In Git, GWCU ensures /.gwcu is in the root .gitignore before truth is created; unsafe ignore setup makes persistence fail closed.

Host contradiction

[TOOL #1] profile.sh recover → cached profile → refresh only if stale/missing → diagnose.sh → Cua health → portal/session facts → observer facts → one deterministic next action

The model never pays separate turns for read → interpret → refresh → interpret → diagnose → interpret.

Remote Desktop, explained once

GNOME is naming a local compositor permission.

Cua uses org.freedesktop.portal.RemoteDesktop to obtain an EIS/libei pointer + keyboard session. GWCU installs no RDP/VNC server or raw-input daemon. On a fresh install, the terminal explains the handshake and counts down 3 → 2 → 1 before the GNOME prompt. The bootstrap moves the pointer once: no click, no key.
