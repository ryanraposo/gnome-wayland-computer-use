gnome-wayland-computer-use

Install· Capabilities· Performance· How it works· Diagnose· Uninstall

Agents have variable success using Linux. This project makes computer use dependable on the most popular Linux desktop out there, Ubuntu 26.

capabilities

One machine. One control authority.

Cua DriverThe only desktop actuator: semantic actions, pixels, pointer, keyboard and verification.
WORLDLINETransient revisions, invalidation, predicates, waits, branches and conflicts.
.gwcuDurable repo/workspace truth worth reusing in another session.
Visual observerScreenCast/PipeWire evidence only when direct machine truth is insufficient.

how it works

Slash it, then talk normally.

/computer-use open YouTube
and play something

/computer-use rename this file
and move it to Downloads
/computer-use status
/computer-use background
/computer-use managed status
/computer-use truths
/computer-use consent
/computer-use doctor
Cua changes the desktop. WORLDLINE knows what changed. .gwcu remembers durable truth. No project RDP/VNC server, ydotool, /dev/uinput fallback, or second actuator.
install

One installer for the full stack.

curl -fsSL https://ryanraposo.github.io/gnome-wayland-computer-use/install.sh | bash
Run as the logged-in desktop user. GNOME may show a “Remote Desktop” prompt for local EIS/libei control. Whole-screen observation has its own ScreenCast consent boundary.
diagnose

Ask the same surface what is wrong.

/computer-use status
/computer-use doctor
/computer-use consent
uninstall

Leave cleanly.

curl -fsSL https://ryanraposo.github.io/gnome-wayland-computer-use/uninstall.sh | bash
Teardown removes GWCU-owned integration and transient runtime state while preserving repo/workspace .gwcu. Cua is preserved by default.
