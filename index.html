The operating model

remember stable invariants → program recurring mechanics → use native Hermes orchestration when orchestration is real → let the model reason only about what is new → Cua executes through one control authority

Cua owns semantic + pixel actions, target/window state, GNOME geometry, exact activation, input delivery, verification, escalation, and refusal. GWCU owns the Ubuntu substrate, deterministic routing/recovery, bounded project memory, and whole-screen observation.

Known target

Zero task-time update checks. Zero broad diagnostics. Zero known-target enumeration. Zero whole-screen prelude when target evidence is enough. Zero blind retry of the same failed delivery shape.

Remote Desktop, explained once

GNOME is naming a local compositor permission.

Cua uses org.freedesktop.portal.RemoteDesktop to obtain an EIS/libei pointer + keyboard session. GWCU installs no RDP/VNC server, raw-input daemon, or project input udev rule. On a fresh install, the terminal explains the handshake and counts down 3 → 2 → 1 before the GNOME prompt. The bootstrap moves the pointer once—no click, no key—and Cua can persist GNOME’s revocable restore token so the normal case does not ask again.

Verify any time with /computer-use consent. Whole-screen ScreenCast permission is a separate capability and appears only when whole-screen observation is requested.

Managed project truths

A tiny cache of durable identity. No diary.

Only low-churn app identity fields are eligible: display name, desktop ID, app ID, StartupWMClass, and app kind. No screenshots, timestamps, user text, task history, coordinates, geometry, focus, or health snapshots. The block is bounded, deterministic, regex-addressable, comment-safe, and subordinate to live Cua state.
