Low-latency ⚕ computer use ⚕ for Ubuntu 26.04 GNOME Wayland

How does it work? →
Route once → cheapest useful evidence → semantic action span → verify at a real decision boundary.
AX first Read text, roles, state, and targetable widgets without paying for pixels when accessibility is enough.
Installed web apps stay apps PWAs and standalone browser apps keep their own identity instead of collapsing into generic Chrome or Firefox.
Fast capture Desktop and screen fallbacks poll for readiness instead of imposing fixed multi-second screenshot sleeps.
Less ritual Verified actions continue in deterministic spans; fresh observations happen when the next decision actually needs them.
curl -fsSL https://ryanraposo.github.io/gnome-wayland-computer-use/install.sh | bash
Runtime-aware: Hermes on PATH gets the full persistent cua-driver integration. Other agents get the same GNOME host stack plus a portable Agent Skill. First-use routing stays off the network; app identity is cached; capture timing is diagnosable; recovery services restart quickly.
Desktop ≠ screen: “desktop” means wallpaper and desktop icons. “screen” means the visible display, including windows. The compositor path preserves focus/workspace/window state; compatibility capture restores and verifies it.
