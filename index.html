authority

Cua changes the desktop. WORLDLINE never does.

On GNOME Wayland, Cua uses the compositor-approved Remote Desktop portal to obtain a local EIS/libei pointer and keyboard session. WORLDLINE and the observer are read-only knowledge infrastructure.

  → libei

  → events / direct facts / optional ScreenCast
  → revision / predicates / conflicts
  → no input injection
durable truth

setup

One installer. One control plane.

The installer qualifies Ubuntu 26.04 GNOME Wayland, repairs the portal/PipeWire/AT-SPI foundation, installs pinned Cua, establishes local control consent, and enables WORLDLINE plus the lazy visual observer.

curl -fsSL https://ryanraposo.github.io/gnome-wayland-computer-use/install.sh | bash

Uninstall:

curl -fsSL https://ryanraposo.github.io/gnome-wayland-computer-use/uninstall.sh | bash

Uninstall removes GWCU-managed WORLDLINE/observer services and transient state while preserving repo/workspace .gwcu content.
